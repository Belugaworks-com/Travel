# DESIGN.md library

73 DESIGN.md files describing the visual style of well-known sites, vendored from
[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) at commit `13be5c0` (MIT, see `LICENSE`).

To build UI in one of these styles, point the agent at it, e.g. "build the search page using `design-md/airbnb/DESIGN.md`",
or copy the chosen file to the repo root as `DESIGN.md` to make it the project default.
